# Retiform plugins

Retiform is shared, governed memory for AI agents. This marketplace distributes:

- **Retiform**, the portable public plugin for ChatGPT, Codex, and compatible Agent Plugins hosts;
- **Retiform Codex lifecycle companion**, the same workflows plus trusted local lifecycle hooks for manual Codex
  desktop installation.

The public plugin connects to `https://api.retiform.ai/mcp` with OAuth dynamic client registration. Packages contain
no credential, tenant identifier, or reviewer account. Review lifecycle hooks before trusting the companion.

Product and setup documentation: https://retiform.ai/docs/agent-plugins/
